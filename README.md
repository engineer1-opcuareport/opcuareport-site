# opcuareport website

The public website for opcuareport: plain HTML and CSS with no build step. Hosted with GitHub Pages.

**This repository is public.** Put only the installer and the website here. Never add source code, `licensing\`, licence private keys, `generated licenses\`, certificates or customer files.

## Release a new version

1. Copy `dist\opcuareport-Setup-<version>.exe` from the app repository into `downloads\`.
2. In `index.html`, update the version in the hero button, the Download section and the download link, then add a Changelog entry.
3. Delete the old installer from `downloads\` if you don't want to offer it any more.
4. Commit and push. GitHub Pages updates in about a minute.

## Preview locally

Open `index.html` in a browser.
"# opcuareport-site"

Every roll reported automatically.

opcuareport connects to your gauge's OPC UA server, follows each roll from start to finish and writes its report as soon as the roll ends, with no one at the PC.

Download version 2.0.1

Features

Automatic roll reports

A report for every roll, made when the gauge's roll changes. Missed rolls are numbered correctly.

Secure OPC UA connection

Connects with signing and encryption. The client certificate is made automatically on the first start.

Runs by itself

Runs as a Windows service task: starts with the PC and restarts if it stops.

Fits your gauge

Lists every tag your gauge offers, so the report layout can be set up for your gauge without a site visit.

Install

  1. Run opcuareport-Setup-2.0.1.exe as administrator. It installs to C:\opcuareport and starts the program automatically.
  2. Open C:\opcuareport\configuration.txt in Notepad (as administrator) and enter the gauge's IP address.
  3. On the gauge, move the opcuareport certificate from Rejected to Trusted.
  4. Install your licence (below).
  5. Check the log: Start menu > opcuareport log. It should show Connected to opc.tcp://...

Licence

Each licence is for one PC and lasts 6 months.

  1. On the PC, open a command prompt and run C:\opcuareport\opcuareport.exe --machine-id. A report made without a licence also shows the machine ID.
  2. Email the machine ID and your company name to CONTACT_EMAIL.
  3. Copy the license.txt you receive to C:\opcuareport\. It applies from the next roll. No restart is needed.
